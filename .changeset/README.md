# Changesets

Hello and welcome! This folder has been automatically generated by `@changesets/cli`, a build tool that works with multi-package repos, or single-package repos to help you version and publish your code. You can find the full documentation for it [in our repository](https://github.com/changesets/changesets).

We have a quick list of common questions to get you started engaging with this project in [our documentation](https://github.com/changesets/changesets/blob/main/docs/common-questions.md).

## Adding a changeset

Every PR that changes the published surface of `@allons-y/dashly` must include a changeset describing the change and the version bump it implies.

```sh
yarn changeset
```

The interactive prompt asks for:

1. **Bump type** — `patch` (bug fix), `minor` (new feature), or `major` (breaking change).
2. **Summary** — a one- or two-line description written for the changelog. Write it for users of the package, not for reviewers of the PR.

The command writes a Markdown file under `.changeset/`. Commit it alongside your changes.

## Releasing

On every push to `main`, the **Release** workflow runs `changesets/action`. If any unreleased changesets exist, it opens (or updates) a "Version packages" PR that:

- Consumes the changeset files
- Bumps `package.json` accordingly
- Prepends a new section to `CHANGELOG.md`

Merging that PR publishes to npm.
