strings

String-manipulation filters for Eleventy.

	firstWord,
	lastWord,
	trim,
	stripWhitespace,
	digitsOnly,
	capitalize,
	title,
} from '@allons-y/dashly/filters/strings';

capitalize(value)

Uppercase the first character of a string and lowercase the rest. Matches the semantics of Nunjucks/Liquid capitalize.

Parameters

NameTypeDefaultDescription
value string

Returns

string | undefined

Examples

// 'Hello world'
capitalize('hello WORLD');
{{ heading | capitalize }}

title(value)

Title-case a string by uppercasing the first letter of each whitespace- delimited word and lowercasing the rest. Useful for converting slugs or raw labels into display headings.

Parameters

NameTypeDefaultDescription
value string

Returns

string | undefined

Examples

// 'The Quick Brown Fox'
title('the QUICK brown fox');
{{ tag | title }}
