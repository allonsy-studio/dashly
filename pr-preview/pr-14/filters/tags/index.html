tags

Tag-list helpers for Eleventy. Use to clean Eleventy's system-tag noise (all, post, posts, etc.) out of a tag list before rendering it.

import { tags } from '@allons-y/dashly/filters/tags';

tags(tagList, extraExclude?, defaultExclude?)

Filter an array of tag strings to exclude system tags and any additional names supplied either as plugin defaults or as a per-call extra list.

The plugin wires its tagsExclude option into the default exclusion list so callers configure once in eleventy.config.js. Per-call extras are added on top, not replacing the defaults.

Parameters

NameTypeDefaultDescription
tagList readonly string[]
extraExclude (optional) readonly string[] Names to exclude in addition to the configured defaults.
defaultExclude (optional) readonly string[] DEFAULT_EXCLUDED_TAGS

Returns

string[]

Examples

// ['design', 'engineering']
tags(['all', 'post', 'design', 'engineering']);
tags(['all', 'post', 'design', 'draft'], ['draft']);
{% for tag in collections.all | getAllTags | tags %} … {% endfor %}
