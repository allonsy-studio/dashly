dashly: the standard library every Eleventy site ends up writing.

Date formatting, reading time, excerpts, RSS-safe HTML, URL handling, locale-aware numbers, & more: bundled into one tree-shakeable package, registered with one plugin line.

Get started Filters Configuration
  • Free & open source · MPL-2.0
  • Eleventy 3+
  • Node 24+
  • Currently in beta
// eleventy.config.js
import dashly from "@allons-y/dashly";

export default function (config) {
	config.addPlugin(dashly, { baseUrl: "https://example.com" });
}

One plugin line

Every filter, transform, & shortcode registers under a sensible default name. Templates can use them straight away.

Works in every engine

Filters register through addFilter, so Nunjucks, Liquid, JavaScript, & 11ty.js templates share the same behavior.

Take only what you need

Import from the narrowest subpath, or opt out per category or per name. Unused code never reaches the build.

Optional peers

Heavy dependencies such as Prettier, PostCSS, & markdown-it are optional peers, installed only when a utility needs them.

What's included

KindCovers
FiltersDates, strings, arrays, HTML, text, numbers, URLs, tags, & debugging.
TransformsPrettier formatting, HTML minification, attribute cleanup, & a PostCSS helper.
Shortcodes{% year %} for always-current footer copyrights.
