Transforms

Transforms process built output. The prettier, htmlmin, & clean-attrs modules export factories that return a function to pass to addTransform; postcss exports a helper for CSS bundles. Peer dependencies load on first use, so a transform only needs its package when it runs.

  • clean-attrs: Eleventy transform that strips eleventy:ignore="" markers left on <img> tags inside <picture> elements.
  • htmlmin: Eleventy transform that minifies HTML output via html-minifier-terser.
  • postcss: PostCSS processing helper for Eleventy bundles or addExtension('css', ...) setups.
  • prettier: Eleventy transform that runs Prettier over HTML, XML, and SVG output.

clean-attrs

Eleventy transform that strips eleventy:ignore="" markers left on <img> tags inside <picture> elements. The official eleventyImageTransformPlugin only clears the attribute on bare <img> elements; this transform finishes the job.

createCleanAttrsTransform(options?)

Create the attribute-cleanup transform.

Parameters

Name Type Default Description
options (optional) object
options.attrs (optional) string[] Additional attribute names to strip. Defaults to ['eleventy:ignore'].

Returns

(content: string) => string

htmlmin

Eleventy transform that minifies HTML output via html-minifier-terser. Requires html-minifier-terser as a peer dependency.

createHtmlMinTransform(options?)

Create the HTML minification transform. By default it runs only when process.env.ELEVENTY_ENV === 'production'; pass production: false to always run or production: true to enforce the gate explicitly.

Parameters

Name Type Default Description
options (optional) object
options.production (optional) boolean When true, only run in production. Defaults to true.
options.minifier (optional) import('html-minifier-terser').Options Options forwarded to html-minifier-terser.

Returns

(content: string, outputPath?: string) => Promise<string>

postcss

PostCSS processing helper for Eleventy bundles or addExtension('css', ...) setups. Requires postcss as a peer dependency.

processCSS(content, inputPath, outputPath, config?)

Run a CSS string through PostCSS using the plugins and options supplied in config (the shape returned by postcss-load-config). If a source map is produced it is written next to the CSS output as <name>.css.map.

Parameters

Name Type Default Description
content string
inputPath string
outputPath string
config (optional) { plugins?: import('postcss').AcceptedPlugin[], options?: import('postcss').ProcessOptions }

Returns

Promise<string>

prettier

Eleventy transform that runs Prettier over HTML, XML, and SVG output. Requires prettier as a peer dependency.

createPrettierTransform(options?)

Create the Prettier transform. Bind to an Eleventy transform with config.addTransform('prettier', createPrettierTransform()).

Parameters

Name Type Default Description
options (optional) object
options.extensions (optional) string[] File extensions to format (default: html/xml/svg).
options.prettier (optional) import('prettier').Options Prettier options (merged on top of dashly defaults).

Returns

(content: string) => Promise<string>
