Features

  • One plugin line

    Every filter, transform, & shortcode registers under a sensible default name. Templates can use them straight away.

  • Works across engines

    Filters register through addFilter, so Nunjucks, Liquid, 11ty.js, & Handlebars templates share the same behavior. Two async filters cannot run in Handlebars.

  • Take only what you need

    Import from the narrowest subpath, or opt out per category or per name. Unused code never reaches the build.

  • Optional peers

    Heavy dependencies such as Prettier, PostCSS, & markdown-it are optional peers, installed only when a utility needs them.
