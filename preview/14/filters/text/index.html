text

In Filters

Text-analysis filters: word counting, excerpting, and reading-time estimation. Strip HTML so callers can feed rendered post content directly.

wordCount(value)

Count whitespace-delimited words in a string. HTML tags are stripped before counting so rendered post content can be passed in directly.

Parameters

Name Type Default Description
value string

Returns

number

Examples

readingTime(value, wpm?)

Estimate reading time in minutes for a block of text. Strips HTML, counts words, divides by wpm (default 200), and rounds to the nearest whole minute with a floor of 1.

Accepts either a string (counted internally) or a pre-computed word count number.

Parameters

Name Type Default Description
value string | number
wpm (optional) number 200 Words per minute.

Returns

number : Whole-minute estimate, minimum 1.

Examples

excerpt(value, n?, unit?)

Pull an excerpt from a string. Positive n returns the first N units; negative n returns the last |N| units. HTML tags are stripped first. Appends an ellipsis on the trimmed side when the input is actually cut.

Parameters

Name Type Default Description
value string
n (optional) number 30 Word/char count. Negative for trailing slice.
unit (optional) 'words' | 'chars' 'words'

Returns

string
