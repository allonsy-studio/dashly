Filters

Filters are plain functions registered with addFilter, so they work in Nunjucks, Liquid, & 11ty.js (JavaScript) templates. This entry re-exports every filter module; for narrower bundles, import directly from a subpath (e.g. @allons-y/dashly/filters/dates).

  • arrays: Array-manipulation filters for Eleventy.
  • dates: Date-related filters for Eleventy.
  • debug: Debugging filters for rendering template data into output for inspection.
  • html: HTML-related filters for Eleventy.
  • numbers: Locale-aware number-formatting filters built on Intl.NumberFormat.
  • objects: Object-related filters for Eleventy.
  • strings: String-manipulation filters for Eleventy.
  • tags: Tag-list helpers for Eleventy.
  • text: Text-analysis filters: word counting, excerpting, and reading-time estimation.
  • urls: URL-related filters for Eleventy.

arrays

Array-manipulation filters for Eleventy. Nunjucks & Liquid have native first / last / reverse filters, but 11ty.js (JavaScript) templates & Handlebars do not. Registering these via dashly makes them available in all four, as checked by test/engines.test.js.

first(value, n?)

Return the first item of an array, or the first n items if a count is supplied. With no count, matches Nunjucks first (single item). With a count, returns the first N items — covers the "limit / head" use case.

dateFormat(value, options?, locale?)

Format a date using Intl.DateTimeFormat. Returns the input unchanged on falsy or unparseable values so templates can render gracefully.

Defaults to timeZone: 'UTC' so a date-only string like '2026-01-15' (which Date parses as midnight UTC) renders as "15 January" everywhere, not "14 January" on machines west of Greenwich. Pass timeZone in options to override.

Parameters

Name Type Default Description
value string | number | Date
options (optional) Intl.DateTimeFormatOptions
locale (optional) Intl.LocalesArgument 'en-US'

Returns

string | number | Date : The formatted string, or value unchanged when it is falsy or unparseable.

relativeDate(value, locale?, options?)

Format a date as a locale-aware relative phrase (e.g. "2 days ago", "in 3 months"). Wraps Intl.RelativeTimeFormat.

The reference point is now by default but can be overridden — useful for stable build output and for testing.

options.style (optional) Intl.RelativeTimeFormatStyle 'long'
options.numeric (optional) 'auto' | 'always' 'auto' 'auto' produces "yesterday" / "tomorrow"; 'always' forces "1 day ago".

html

HTML-related filters for Eleventy.

  • cleanForRSS requires posthtml as a peer dependency.
  • renderMarkdown requires markdown-it as a peer dependency or a user-provided renderer instance.
  • Both are async & do not work in Handlebars; see each filter for why.

stripTags(value)

Strip every HTML tag from a string, leaving only text content. Zero-dep regex pass — for opinionated tag-aware stripping (RSS feeds, custom elements, permalinks), use cleanForRSS instead.

Internal whitespace is collapsed and the result is trimmed.

Parameters

Name Type Default Description
value string

Returns

string

Examples

nl2br(value)

Replace newline characters with <br> tags. Handles \r\n, \r, and \n. Useful for rendering plain-text strings (form responses, YAML data) as HTML while preserving line breaks. Preserves the trailing newline so the HTML source stays readable.

Parameters

Name Type Default Description
value string

Returns

string

Examples

cleanForRSS(html, options?)

Strip tags and elements that are unsafe or undesirable in RSS/Atom feeds.

By default this removes script/style/embed/etc. tags and header-anchor permalink <a> elements inserted by markdown-it-anchor. Pass customTags to strip additional tags (e.g. web components like lite-youtube).

Async, so it does not work in Handlebars. The filter returns a Promise because it loads posthtml with a dynamic import() on first use. Nunjucks, Liquid, & 11ty.js await it. Handlebars helpers are synchronous & cannot await, so {{cleanForRSS html}} renders [object Promise]. Compute the value in a data file, eleventyComputed, or a JS template instead, & pass the resulting string to the Handlebars template.

Parameters

Name Type Default Description
html string
options (optional) object
options.unsafeTags (optional) string[] Override the default unsafe-tag list.
options.customTags (optional) string[] [] Additional tag names to strip (e.g. custom elements).
options.stripPermalinks (optional) boolean true Remove <a class="header-anchor"> nodes.

Returns

Promise<string>

renderMarkdown(value, options?)

tags

Tag-list helpers for Eleventy. Use to clean Eleventy's system-tag noise (all, post, posts, etc.) out of a tag list before rendering it.

tags(tagList, extraExclude?, defaultExclude?)

Filter an array of tag strings to exclude system tags and any additional names supplied either as plugin defaults or as a per-call extra list.

The plugin wires its tagsExclude option into the default exclusion list so callers configure once in eleventy.config.js. Per-call extras are added on top, not replacing the defaults.

readingTime(value, wpm?)

Estimate reading time in minutes for a block of text. Strips HTML, counts words, divides by wpm (default 200), and rounds to the nearest whole minute with a floor of 1.

Accepts either a string (counted internally) or a pre-computed word count number.

urls

URL-related filters for Eleventy.

validateURL(url)

Ensure a URL is safe to render. Passes through mailto:, tel:, fragments, relative paths, and URLs already prefixed with http(s):. Everything else is prefixed with https://. All output is URI-encoded.

Note: pass the full URL string. This filter is not context-aware.

Parameters

Name Type Default Description
url string

Returns

string

absoluteUrl(path, baseUrl?)

Resolve a path or URL against a base, producing an absolute URL. Useful for canonical tags, OpenGraph metadata, JSON-LD, and RSS/Atom feeds — anywhere a fully-qualified URL is required.

Already-absolute URLs are returned unchanged. mailto:, tel:, and fragment-only (#section) inputs pass through as-is. Empty/nullish input returns an empty string.

Parameters

Name Type Default Description
path string A relative path, absolute path, or full URL.
baseUrl (optional) string The site's origin (e.g. https://example.com). Trailing slashes are tolerated. If omitted, the input is returned unchanged — useful during local development.

Returns

string
