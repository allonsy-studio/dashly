arrays

In Filters

Array-manipulation filters for Eleventy. Nunjucks & Liquid have native first / last / reverse filters, but 11ty.js (JavaScript) templates & Handlebars do not. Registering these via dashly makes them available in all four, as checked by test/engines.test.js.

first(value, n?)

Return the first item of an array, or the first n items if a count is supplied. With no count, matches Nunjucks first (single item). With a count, returns the first N items — covers the "limit / head" use case.

Parameters

Name Type Default Description
value readonly T[]
n (optional) number

Returns

T | T[] | undefined

Examples

groupBy(value, keyOrFn)

Group array items by a key, a dot-path, or a function. Returns a plain object keyed by the grouping value, with each value an array of items.

Parameters

Name Type Default Description
value readonly T[]
keyOrFn string | ((item: T) => unknown) Property name (dot-paths supported, e.g. 'data.year') or selector function.

Returns

Record<string, T[]>

Examples

sortBy(value, keyOrFn, order?)

Sort an array by a key, dot-path, or selector function, without mutating the input. String values are compared with localeCompare; everything else with standard < / >.

Parameters

Name Type Default Description
value readonly T[]
keyOrFn string | ((item: T) => unknown)
order (optional) 'asc' | 'desc' 'asc'

Returns

T[]

Examples

Filter an array by a key/dot-path equality check. When expected is omitted, items where the keyed value is truthy are kept (useful for where(posts, 'data.featured')).
